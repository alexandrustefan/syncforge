# Screenshots

These are actual SyncForge screenshots from a local three-output setup, captured on 2026-10-17.
`menu-bar.png` was supplied by the repository owner; `outputs.jpg`, `equalizer.jpg` and
`calibration.jpg` were captured from the running app without changing audio settings or starting
calibration. The screenshots contain no desktop background or unrelated windows.

Displayed names, volumes, delays and drift estimates are examples. They are not recommended
settings or independent acoustic verification. The images are included under the repository's
MIT license.
